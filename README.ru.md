# Rust World для Blender

[English version](README.md)

Аддон Blender для работы с мирами **Rust** (Facepunch) вне игры:

- **импорт** процедурных и кастомных карт (`.map`): рельеф, вода, дороги, монументы, декор;
- **импорт** демок (`.dem`): все сущности записи (постройки, двери, деплойблы, деревья, игроки, NPC, транспорт) с их движением во времени;
- **загрузка настоящих ассетов игры** (меши, материалы, текстуры) прямо из установленного Rust, на всю карту или только там, где нужно;
- **правка сцены и экспорт новой демки**: двигать и анимировать сущности, открывать и закрывать двери, удалять и добавлять сущности, менять грейд построек, задавать время суток.

Сделано для работы с камерой: собираешь кадр в Blender на настоящей геометрии и проигрываешь его в игре.

> Один файл, без данных игры. Ассеты читаются из твоей установки Rust.

---

## Что нужно

- Blender **4.2+** (разработка и проверка на 5.2).
- Rust через Steam (релиз или staging).
- Один раз интернет, чтобы поставить Python-пакеты экстрактора (UnityPy, Pillow) кнопкой в панели.

## Установка

1. Скачай `rust_world.py`.
2. Blender › *Edit › Preferences › Add-ons › Install from Disk…* › выбери файл и включи **Rust world (.map / .dem)**.
3. В настройках аддона проверь **Rust folder**. Папка находится автоматически по библиотекам Steam, при необходимости укажи её вручную. **Asset cache** по желанию (по умолчанию `<папка Rust>/rust_blender_cache`).
4. Во вьюпорте открой боковую панель (**N**) › вкладка **Rust** › **Install extractor dependencies** (один раз).

## Быстрый старт

1. *File › Import › Rust map (.map)*. Карты лежат в `<Rust>/maps`: карта сервера скачивается туда при подключении.
2. *File › Import › Rust demo (.dem)*. Демки лежат в `<Rust>/demos`.
3. Панель **Rust** › выбери, что грузить, и нажми **Load assets**.
   Выгрузка идёт в фоне с прогрессом. Что уже есть в кеше, повторно не выгружается.
4. Правь сцену, затем *File › Export › Rust demo (.dem)*: получится новый файл рядом с записью.

## Загрузка ассетов

**Load** — что грузить:

| Вариант | Что загружается |
|---|---|
| Whole map | вся карта |
| Selected | выделенные во вьюпорте объекты |
| Inside boxes | всё внутри боксов (**Add load box** ставит бокс в 3D-курсор; двигай, масштабируй, ставь сколько угодно) |
| Around cursor | радиус от 3D-курсора |
| Along camera path | радиус вдоль пути камеры сцены |
| From list | отмеченное в **Prefab list** (поиск, отметка по категории и по выделению, выделение копий) |

**Детализация**

- *LOD0* — полная детализация.
- *Far LOD* — самый дальний LOD, в котором есть меш: только силуэты, очень легко.
- *Monuments as one HLOD mesh* — каждый монумент одним склеенным дальним мешем.
- *Textures* — по умолчанию выключены (только меши и цвета материалов, гораздо быстрее). Их можно догрузить позже, меши из кеша переиспользуются.
- *Hide instances outside* — скрыть всё вне выбранной области.

Для ориентира, карта 2 км: вся карта в режиме *Far LOD + HLOD* — около 0,45 млн полигонов и около 10 с загрузки; полный *LOD0* — около 9 млн полигонов.

**Постройки** получают меш своего грейда (солома / дерево / камень / металл / МВК и скины) и детали стен (углы, половины). **Распашные двери** показаны открытыми или закрытыми и поворачиваются по свойству `Open`.

## Правка и экспорт демки

Экспортированная демка = исходная запись + твои правки. **Всё, что ты не трогал, копируется байт в байт**, исходник никогда не перезаписывается.

Панель **Rust › Demo edit / export**:

- **Key Open / Key On / Key Lock** — переключить флаг у выделенных сущностей на текущем кадре (двери, ящики, свет, печки…).
- **Clone entity** (или обычный *Shift+D*) — новая сущность по образцу существующей: ещё одна дверь, стена, ящик…
- **Grade** у строительного блока (0 солома … 4 МВК), кнопка **Grades** обновляет вид.
- **Time of day** — *As recorded* или *Custom* с анимируемым **Hour**. Панель показывает время из записи на текущем кадре.

Настройки экспорта:

| Настройка | Что делает |
|---|---|
| Recording | какую импортированную демку брать за основу |
| Moved / animated entities | подвинутые или анимированные сущности получают твоё движение (в том числе через анимированного родителя, например пустышку в петле двери) |
| Open / On / Locked keys | записываются ключи флагов; нетронутые флаги остаются как в записи |
| Deleted entities | удалённые в Blender сущности (и их дочерние) вырезаются |
| New (cloned) entities | клоны добавляются как новые сущности |
| Keep only inside load boxes | всё вне боксов вырезается; твой персонаж остаётся всегда |
| Position rate (Hz) | как часто пишутся позиции анимированного (по умолчанию 30) |

Кадр 1 сцены соответствует тому же моменту демки, что и при импорте, поэтому камера, сделанная под демку, совпадает с правками по времени.

## Командная строка (без Blender)

```
python rust_world.py mapinfo   file.map
python rust_world.py demoinfo  file.dem
python rust_world.py demojson  file.dem out.json
python rust_world.py prefabnames <папка Rust> names.json
python rust_world.py extract --rust <папка Rust> --map file.map --dem file.dem [--lod lod0|low] [--hlod] [--no-tex] [--max-tex 1024]
python rust_world.py demoroundtrip file.dem                 # чтение + запись, должно совпасть байт в байт
python rust_world.py demotime in.dem out.dem 17:30           # фиксированное время суток
python rust_world.py demotime in.dem out.dem 6:00-20:00 30   # 06:00 -> 20:00 за 30 с
```

## Как это устроено

Форматы файлов разобраны вручную, заметки лежат в [docs/FORMATS.md](docs/FORMATS.md). Коротко: карты и демки — это protobuf (карты сжаты LZ4), ID префабов — хэш пути ассета, а бандлы игры хранятся несжатыми. Поэтому экстрактор читает их лениво через отображение в память: на ~50 ГБ бандлов уходит несколько сотен МБ памяти. Сами ассеты разбирает UnityPy.

## Известные ограничения

- Игроки и NPC показаны простыми болванками: одежда собирается игрой во время работы.
- Детали фундаментов и крыш берутся набором по умолчанию; точно по записи идут только детали стен.
- В Blender поворачиваются только одинарные распашные двери; двойные двери, ворота и гаражные двери пока нет.
- Часть шейдеров упрощена (слои смешивания, детали terrain-blend); рельеф раскрашен по сплатам, а не текстурами рельефа игры.
- Демки привязаны к версии игры: после месячного обновления старые (и сгенерированные) демки могут перестать проигрываться.
